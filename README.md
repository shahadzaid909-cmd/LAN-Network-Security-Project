# LAN Network Security Project

An academic **IT221 computer networking project** exploring local area network (LAN) setup, connectivity testing, remote-access tools, and basic network security controls.

## Project overview

The team described a local network connecting three laptops to a router in a **star topology**, with static IP addresses assigned to the devices. The report documents connectivity checks and explores host- and router-level network security.

## Topics covered

| Topic | Project documentation |
| --- | --- |
| LAN configuration | Router, three laptops, star topology, static IP addressing |
| Connectivity testing | Ping tests between LAN devices; report records successful replies with no packet loss |
| Remote access | TeamViewer LAN mode interface and setup exploration; completion of a remote session is not established |
| Windows Defender Firewall | Firewall configuration interface and proposed outbound blocking rule; successful enforcement is not demonstrated |
| MAC address filtering | Huawei router MAC filtering settings, device lists, and reported connection restriction |

## Learning outcomes

- Understand IP addressing and connectivity testing on a local network
- Use `ping` to investigate network reachability and latency
- Explore remote administration tools
- Understand firewall rule configuration and its role in network protection
- Explore MAC filtering as an additional, limited access-control measure

## Project scope

This is a **documentation-based networking project**, not a software application or a penetration-testing toolkit. Some actions in the original report are presented as theoretical or illustrative, so they should not be interpreted as independently verified completed security tests.
